## SDK surface (verified against installed 0.0.38 type declarations — confirm at runtime during this card)

- `CoreCompactionConfig` (`dist/types/config.d.ts:61`): `enabled`, `strategy: "basic" | "agentic"`, `thresholdRatio`, `reserveTokens`, `preserveRecentTokens`, `contextWindowTokens`, `summarizer: CoreCompactionSummarizerConfig`, `compact` callback.
- `StartSessionInput.config` (`RuntimeSessionConfig`, `dist/runtime/host/runtime-host.d.ts:13`) accepts `compaction` **without** the `compact` callback; `localRuntime.compaction` accepts `compact`.
- `summarizer` carries its own `providerId/modelId/apiKey/baseUrl/headers/knownModels/providerConfig/maxOutputTokens` — this is how compaction stays on the local model.
- SDK defaults for reference: window 200000, threshold 0.95, reserve 16384, preserveRecent 20000, summary maxOutput 1024 (`dist/extensions/context/compaction-shared.d.ts`).

## Implementation

1. New `src/cline-sdk/cline-compaction-config.ts`:
   - `buildClineCompactionConfig({ launchConfig, effectiveLimit, settings }): Omit<NonNullable<CoreSessionConfig["compaction"]>, "compact">` where:
     - `enabled: true`, `contextWindowTokens: effectiveLimit.limitTokens` (B-2-2),
     - `strategy: settings.compactionStrategy ?? "basic"` (settings field lands in B-2-9; until then read only defaults — keep the parameter shape stable),
     - `thresholdRatio: 0.8` (proposed tuning value per B-2.4; B-2-5 tunes/verifies),
     - `reserveTokens`: output reserve = provider `maxTokens` if present in settings, else a documented default (start at SDK's 16384),
     - `preserveRecentTokens`: SDK default 20000 unless overridden later,
     - `summarizer`: `{ providerId, modelId, apiKey, baseUrl, headers }` copied from the **same local launch config** (requirement #1), `maxOutputTokens: 1024`.
   - Import types only from the public `@clinebot/core` entry via `src/cline-sdk/sdk-runtime-boundary.ts` (add the re-export there if missing) — no deep `dist/` imports.
2. `src/cline-sdk/cline-task-session-service.ts`: add optional `compaction` field to `StartClineTaskSessionRequest` (~59); pass it to the runtime.
3. `src/cline-sdk/cline-session-runtime.ts:~207`: add `compaction` to the `sessionHost.start` config object.
4. `src/trpc/runtime-api.ts:~168`: build the config from the resolved launch config + B-2-2 resolver and pass it in.
5. **Keep** `retryAfterContextOverflow` (`cline-task-session-service.ts:~289`) as a backstop. B-3 owns its repair; do not remove or rewrite it here.
